# Certificado PostgreSQL de Supabase

Descargar el certificado raiz desde:

`Supabase > Database > Settings > SSL Configuration > Download Certificate`

Guardarlo en esta carpeta con el nombre exacto:

`supabase-ca.crt`

El certificado raiz es publico. Nunca guardar aqui la URL de conexion, la
contrasena de PostgreSQL, claves `service_role` ni secretos del servidor.
